# The Reserve — HTML & Bootstrap Demo

A single-page restaurant website built with plain **HTML**, **Bootstrap 5**, and a
little **vanilla JavaScript**. Great for teaching how the three pieces of a web page
fit together.

## Project structure

```
the-reserve/
├── index.html        # Page structure (the HTML)
├── css/
│   └── styles.css    # Custom brand styles on top of Bootstrap
└── js/
    └── script.js     # Interactivity (menu filter, modals, bookings…)
```

## How to run

No build tools needed — just open `index.html` in a web browser.
(Bootstrap and the fonts load from a CDN, so an internet connection is required.)

## What students can learn here

- **HTML structure**: semantic tags (`header`, `main`, `section`, `footer`)
- **Bootstrap layout**: the grid (`row` / `col-*`), navbar, modals, utility classes
- **Custom CSS**: variables, custom buttons, floating-label inputs, animations
- **JavaScript basics**: `addEventListener`, reading `data-*` attributes, and
  saving data in the browser with `localStorage`
